# MirrorMind — AI Interview Coach 🎤

A voice-based interview preparation tool that generates role-specific questions from any job description, transcribes your spoken answers in real time, and evaluates your response with a rating and confidence score.

## Live Demo
[GitHub Repo](https://github.com/Vishal-subudhi/mirrormind)

## Features
- Paste any job description → GPT-4 generates 3–10 tailored interview questions
- Record your answer directly in the browser via microphone
- Live transcription of your spoken answer using Whisper
- AI evaluation of each answer — relevance, depth, clarity
- Confidence score per answer based on response quality
- Average score tracker across all answers in a session
- PocketBase backend for session and response storage
- Deployed frontend on Vercel, backend on Render

## Tech Stack
- Next.js (App Router)
- OpenAI GPT-4 (question generation + answer evaluation)
- Whisper API (speech-to-text transcription)
- PocketBase (backend database — self-hosted on Render)
- MediaRecorder API (browser microphone recording)
- Tailwind CSS v3
- Vercel (frontend hosting)
- Render (backend hosting)

## How it works

```
User pastes job description
  → GPT-4 generates relevant interview questions
  → User clicks Record
  → MediaRecorder captures audio from browser mic
  → Audio sent to Whisper → transcribed to text
  → Transcribed answer sent to GPT-4 for evaluation
  → AI returns: rating (1-10) + confidence score + feedback
  → Response saved to PocketBase
  → Average score updated across session
```

## How to run locally

### Frontend
```bash
cd mirrormind-frontend
npm install
npm run dev
```

### Backend (PocketBase)
```bash
# Download PocketBase for your OS from pocketbase.io
./pocketbase serve
```

Create `.env.local` in the frontend:
```
NEXT_PUBLIC_POCKETBASE_URL=http://127.0.0.1:8090
OPENAI_API_KEY=your_openai_key
```

## Key Concepts Used

### Question Generation (GPT-4)
```js
const questions = await openai.chat.completions.create({
  model: "gpt-4",
  messages: [
    {
      role: "system",
      content: `You are an expert technical interviewer. 
      Generate 5 specific interview questions based on this 
      job description. Return as a JSON array of strings.`
    },
    { role: "user", content: jobDescription }
  ]
})
```

### Voice Recording (MediaRecorder API)
```js
const stream = await navigator.mediaDevices.getUserMedia({ audio: true })
const recorder = new MediaRecorder(stream)
const chunks = []

recorder.ondataavailable = (e) => chunks.push(e.data)
recorder.onstop = async () => {
  const audioBlob = new Blob(chunks, { type: 'audio/webm' })
  const transcript = await transcribeWithWhisper(audioBlob)
  const evaluation = await evaluateAnswer(transcript, currentQuestion)
}

recorder.start()
```

### Answer Evaluation (GPT-4)
```js
const evaluation = await openai.chat.completions.create({
  model: "gpt-4",
  messages: [
    {
      role: "system",
      content: `Evaluate this interview answer. Return JSON with:
      { rating: 1-10, confidence: 1-100, feedback: string }`
    },
    {
      role: "user",
      content: `Question: ${question}\nAnswer: ${transcript}`
    }
  ]
})
```

### PocketBase (why it was chosen)
PocketBase is a single-file Go backend with a built-in SQLite database and admin UI. No complex setup — download, run, done. Hosted on Render's free tier. Stores interview sessions, questions, transcripts, and scores.
